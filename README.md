# 🌍 ESG Trends & Impact Analysis Dashboard

### 🎯 Business Problem
Organizations tracking Environmental, Social, and Governance (ESG) performance across countries had no unified way to compare indicator trends, benchmark country performance, or monitor year-over-year progress in one place.

### ✅ Solution
Built an interactive Power BI dashboard that cleans and models ESG indicator data across countries and years, with DAX-driven KPIs and dynamic filtering so users can explore trends, compare performance, and track YoY growth on demand.

### 🛠 Tools & Techniques
`Power BI Desktop` `Power Query` `DAX`
— data cleaning (removing negative/invalid values, handling missing data, type conversion), KPI calculation via DAX (Total/Average ESG Value, YoY Growth %), interactive visuals (line, donut, bar charts, KPI cards, slicers).

### 📊 Dataset
ESG indicator values across multiple countries and years, filtered to valid positive values for accurate KPI calculation.

### 🔍 Key Findings
- ESG values show a growth trend until recent years
- Certain regions consistently outperform others on ESG metrics
- Migration, patents, and life expectancy are among the most significant contributing indicators
- YoY growth tracking surfaces meaningful shifts in country-level performance
